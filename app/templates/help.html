Quick guide for using the Markdown Conversion Tool.

How To Use The App

  • Select output format: DOCX or PDF.
  • Upload a main markdown file, or upload a ZIP package containing your markdown project.
  • Optionally upload referenced files (images, etc.) as multiple files.
  • If template styles are enabled, leave the checkbox checked to apply the configured Word template.
  • Click Convert and Download.

Input Options

  • Main markdown file: quick single-document workflow.
  • ZIP package: best for projects with nested folders and multiple assets.
  • Referenced files: for non-ZIP workflows, upload any local files referenced by your markdown.

Markdown Writing Syntax

Common syntax patterns:

# Heading 1 ## Heading 2 **bold text** *italic text* - bullet item - another bullet 1. numbered item 2. numbered item [Link text](https://example.com) ![Image alt text](images/plot.png) ```python print("code block") ```

Image References

  • Use relative paths like images/plot.png in your markdown.
  • The converter checks local image references before running pandoc.
  • If a referenced file is missing, upload it or include it in your ZIP package.
